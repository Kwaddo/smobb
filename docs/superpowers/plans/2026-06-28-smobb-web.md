# S.M.O.B.B. Web/Mobile (Phase 4) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development for Tasks 1–3 (Rust, cargo/wasm-verifiable). Task 4 is controller-run (needs trunk + a browser + network). Steps use checkbox (`- [ ]`) syntax.

**Goal:** Run S.M.O.B.B. in the browser + as an installable PWA, reusing the ratatui TUI via ratzilla.

**Architecture:** Extract the portable App+ui into `smobb-tui-core` (neutral `Key` enum, ratatui without crossterm, `web-time` clock). The native `smobb-tui` and a new wasm `smobb-web` (ratzilla) both depend on it. A web shell adds a terminal-styled page, a touch control bar (synthetic key events), and PWA install/offline.

**Tech Stack:** Rust 2021, `smobb-core`, `ratatui 0.29` (default-features=false in core), `ratzilla 0.2`, `web-time 1`, `crossterm` (native only), `trunk` (bundler).

## Global Constraints

- ratzilla **0.2** (re-exports ratatui 0.29) + web-time **1**; cache pre-warmed for `wasm32-unknown-unknown`.
- `smobb-tui-core` must NOT depend on crossterm; its `ratatui` is `default-features = false, features = ["unstable-rendered-line-info"]`. It must compile for BOTH native and `wasm32`.
- The App takes a crate-defined `Key` enum (not crossterm/ratzilla `KeyCode`). Backends translate to `Key`.
- Root `Cargo.toml` sets `default-members` to the native-safe crates (`smobb-core`, `smobb-tui-core`, `smobb-tui`) so bare `cargo build`/`cargo test` skip `smobb-web`. Build `smobb-web` only with `--target wasm32-unknown-unknown`. Do NOT use `cargo build --workspace` anymore (it would build `smobb-web` for native and fail).
- Cargo: `source "$HOME/.cargo/env" && CARGO_NET_OFFLINE=true cargo <cmd>`.
- DO NOT COMMIT (user handles git). DO NOT run any git. Subagents: never run `trunk` or a browser (offline). Do not run the native TUI / TUI examples interactively.
- Behavior of the existing engine + TUI must be preserved (this is a refactor + new frontend, no gameplay change).

```rust
use std::time::Duration;
use web_time::Instant;
use ratatui::crossterm::event::{self, Event, KeyCode, KeyEvent, KeyEventKind, KeyModifiers};
use smobb_core::content;
use smobb_core::engine::Engine;
use smobb_tui_core::{app::App, app::Key, ui};

fn to_key(k: &KeyEvent) -> Option<Key> {
    let ctrl = k.modifiers.contains(KeyModifiers::CONTROL);
    Some(match k.code {
        KeyCode::Char('c') if ctrl => Key::CtrlC,
        KeyCode::Char(c) => Key::Char(c),
        KeyCode::Enter => Key::Enter,
        KeyCode::Backspace => Key::Backspace,
        KeyCode::Tab => Key::Tab,
        KeyCode::F(1) => Key::F1,
        KeyCode::F(2) => Key::F2,
        KeyCode::Up => Key::Up,
        KeyCode::Down => Key::Down,
        KeyCode::PageUp => Key::PageUp,
        KeyCode::PageDown => Key::PageDown,
        KeyCode::Esc => Key::Esc,
        _ => return None,
    })
}

fn main() -> std::io::Result<()> {
    let mut terminal = ratatui::init();
    let mut app = App::new(Engine::new(content::load()));
    let res = run(&mut terminal, &mut app);
    ratatui::restore();
    res
}

fn run(terminal: &mut ratatui::DefaultTerminal, app: &mut App) -> std::io::Result<()> {
    let tick = Duration::from_millis(30);
    while !app.quit() {
        terminal.draw(|f| ui::render(f, app))?;
        if event::poll(tick)? {
            if let Event::Key(k) = event::read()? {
                if k.kind == KeyEventKind::Press {
                    if let Some(key) = to_key(&k) { app.key(key); }
                }
            }
        }
        app.tick(Instant::now());
    }
    Ok(())
}
```

```rust
use std::cell::RefCell;
use std::rc::Rc;
use ratzilla::ratatui::Terminal;
use ratzilla::{DomBackend, WebRenderer};
use ratzilla::event::{KeyEvent, KeyCode};
use smobb_core::content;
use smobb_core::engine::Engine;
use smobb_tui_core::{app::App, app::Key, ui};

fn to_key(k: &KeyEvent) -> Option<Key> {
    Some(match k.code {
        KeyCode::Char('c') if k.ctrl => Key::CtrlC,
        KeyCode::Char(c) => Key::Char(c),
        KeyCode::Enter => Key::Enter,
        KeyCode::Backspace => Key::Backspace,
        KeyCode::Tab => Key::Tab,
        KeyCode::F(1) => Key::F1,
        KeyCode::F(2) => Key::F2,
        KeyCode::Up => Key::Up,
        KeyCode::Down => Key::Down,
        KeyCode::PageUp => Key::PageUp,
        KeyCode::PageDown => Key::PageDown,
        KeyCode::Esc => Key::Esc,
        _ => return None,
    })
}

fn main() -> std::io::Result<()> {
    let app = Rc::new(RefCell::new(App::new(Engine::new(content::load()))));
    let backend = DomBackend::new()?;
    let terminal = Terminal::new(backend)?;

    terminal.on_key_event({
        let app = app.clone();
        move |ke| {
            if let Some(key) = to_key(&ke) {
                app.borrow_mut().key(key);
            }
        }
    });

    terminal.draw_web(move |f| {
        {
            let mut a = app.borrow_mut();
            a.tick(web_time::Instant::now());
        }
        ui::render(f, &app.borrow());
    });

    Ok(())
}
```
> If a ratzilla 0.2 API detail differs (e.g. `KeyEvent` field names, or `draw_web`/`on_key_event` signatures), adapt minimally to the installed crate (confirmed shape: `event::KeyEvent { code: KeyCode, ctrl: bool, shift: bool }`, `KeyCode::{Char,F,Enter,Backspace,Tab,Up,Down,PageUp,PageDown,Esc}`; `DomBackend::new()? -> backend`, `Terminal::new(backend)?`, `terminal.on_key_event(FnMut(KeyEvent))`, `terminal.draw_web(FnMut(&mut Frame))`). Borrow discipline: never hold a `borrow_mut` across `ui::render`'s `&app.borrow()` — the block above drops the mut borrow before the render borrow.
